# 개발 중 기록

## Part1
### 2026-09-30
- 개미수열 가운데 두자리수 출력
- 현재 가운데 두자리수를 알아내는 공식이나 규칙은 확인된 바 없음
- 일단 해당 항의 값을 구한 후 그 값에서 가운데 두자리수를 찾는 방식
- 필요 기능
    - 값 구하기
        - 연속된 같은 수 찾기
            - 연속된 같은 수가 4개 이상이 될 일은 없음(연속된 같은 수를 한묶음으로 셈. 2가 2개, 2가 2개로 생성하려면 이전 항에서 따로 셌어야 했기 때문.)
            - 이때 출력시 List[str]타입으로 나와야함
        - 연속된 같은 수 개수 구하기
        - 개수를 앞에 뒤에는 그 같은수 하나만 붙임

### 2026-10-01
- 어제까지 완료된 사항
    - 연속된 같은 수 찾아서 그것들을 하나의 문자열로 묶음.
    - 연속된 같은 수가 없을 땐 혼자서 문자열 하나가 됨.
    - 그리고 그 문자열들의 리스트를 반환하는 함수 구현 완료.

- 오늘 완료한 사항
    - 문자열들로 된 리스트를 받아서 이를 개미수열처럼 바꾸는 함수 구현
    - 항을 입력하면 해당 항에 해당하는 개미수열 값을 출력하는 함수 구현
    - 해당 수열에서 가운데 숫자 2개 출력하는 함수 구현
    - 중간에 integer로 타입을 바꾸니 항이 커지면 integer 자릿수 초과하는 문제 발생
        - 이는 계속 string으로 진행 후 마지막에 두자리만 integer로 바꾸는 방식으로 해결
