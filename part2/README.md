# 건강검진 설명 AI Assistant

## 설명
- Mock API에 있는 건강검진 데이터를 가져와 이를 바탕으로 설명해주는 AI Assistant

## 구성요소

### node
- 각각의 노드는 특정한 역할을 수행
- start_node : 사용자의 입력에 대한 의도 분류, 사용해야할 노드 생성 및 워크플로우 생성
- mapping_node : 사용자의 입력에 특정 항목에 대한 설명이 필요할 경우 특정 항목과 사용자 입력에 있는 항목과 매칭
- total_explain_node : 건강검진 데이터(전체)를 바탕으로 설명해주는 데이터
- is_normal_node : 건강검진 데이터(특정항목)가 정상인지 비정상인지 판별
- chat_node : 일상적인 대화 및 건강검진 조회와 관련 없는 요청 

### 각 노드별 설명
- start_node
    - 사용자의 입력을 받아 사용해야할 노드를 선택, 선택된 노드들로 구성된 워크플로우 생성
    - 사용자의 의도도 분류

- mapping_node
    - 사용자의 입력과 그에 맞는 항목을 매핑
    - 이는 is_normal_node에 사용될 예정

- total_explain_node
    - 건강검진 전체 결과가 어떠한지 전체적으로 설명

- is_normal_node
    - 특정 건강검진 항목이 정상인지 판별

### 노드 분리 이유
- LLM 입력값을 최소화 하고자 함
- 일부만 확인하고 싶은데 전체 데이터가 들어가면 품질 하락 및 효율성 하락 우려
- 그래서 전체, 일부 분리
- 일부의 경우 사용자의 요청에서 항목에 맞게 매핑 후 이를 토대로 일부 데이터만 가져옴
- 만약 아무런 관련이 없는 요청이 들어왔을 때 엉뚱한 답변이나 에러가 나지 않게 하기 위해 chat 노드 구성

## AI 사용 내역
- 프롬프트 초안 작성
- 에러 원인 탐색
- 랭그래프 코드 초안 작성
