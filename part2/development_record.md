# MockAPI로 데이터를 받아온 후 이를 기반으로 채팅


# 구현 방향
- 우선 Mock API를 통해 데이터를 가져옴
    - 데이터를 API를 통해 가져왔다는건 어딘가 저장된 곳에서 가져온 것이거나, 생성된 후 가져온 거라 추측
    - 즉 가져온 데이터를 다시 저장할 필요는 없다고 보임

- Langgraph를 활용해 Q&A 시스템 개발
    - Langgraph를 활용하는걸 권장하는 것은 여러 에이전트를 오케스트레이션 한다고 생각함
    - MockAPI를 통해 가져오는 데이터 역시 referenceList 부분이 여러 딕셔너리로 되어있음
    - 그러면 의도 분류 및 워크플로우 생성, 함수 호출(정상 여부 판단), 결과 요약본 설명, 특정 수치 정상 여부 판단, 최종 대답 노드를 만든 후 의도 분류 및 워크플로우는 시작, 최종 대답은 마지막에 고정
    - 각 노드마다 필요한 데이터만 주입
