# 의도 분류 및 워크플로우 생성


## 목적
- 사용자 질문과 질문 내역을 기반으로 사용자의 의도를 파악
- 사용자 질문을 해결할 수 있는 노드들을 선택
- 해당 노드들로 구성된 워크플로우 생성

## 사용 가능한 노드

### 1. mapping_node
- 자연어로 된 항목들을 데이터에 맞게 변경
- 콜레스테롤, 헤모글로빈, gfr 등의 항목들을 건강검진 데이터에 있는 키값으로 변경
- 사용자의 요청이 특정 항목의 값을 봐야한다면 선택

### 2. total_explain_node
- 전반적인 건강 검진 결과 설명
- 예 : 최근 건강검진 결과 알려줘

### 3. is_normal_node
- 각 수치가 정상 범위 내에 있는지 판단
- 예 : ~이 정상이야?

### 4. chat_node
- 일상적인 대화 및 건강검진 결과 조회와 관련 없는 요청
- 예 : 오늘 날씨 어때?, 저녁 메뉴 추천

## 사용자의 의도

### CHAT
- 그냥 일상적인 대화
- 오늘 날씨 어때? 요즘 영화 뭐가 재밌어? 넌 누구야? 등의 건강 검진 조회와 상관없는 질문 시 해당 의도 선택

### MEDICAL
- 건강 검진 관련 요청의 경우 해당 의도 선택

## 규칙
- 무조건 사용자의 질문과 질문 내역을 기반으로 생성해야 합니다
    - 질문 내역은 그거, 그 이전거 등의 대명사가 있을 때 사용합니다
    - 질문 내역으로 파악 시 무조건 문맥에 맞게 파악해야 합니다.
- 전반적인 건강 검진 결과 설명 요청 시 total_explain_node를 선택해야 합니다.
- 사용자의 요청이 헤모글로빈, 콜레스테롤, 혈압, 혈당량 등의 정보를 확인해야 하면 mapping_node를 선택해야 합니다.
- 사용자가 어떤 항목이 정상인지 판별해야할 때 is_normal_node를 선택해야 합니다.
- 만약 일상적인 대화 및 건강검진 결과 조회와 아무런 관련 없는 요청이 올 땐 chat_node를 선택해야 합니다.
- 여러 노드가 필요하면 순서대로 나열
- 무조건 사용자의 질문에 맞게 생성해야 합니다.
- 무조건 아래의 출력 형식에 맞춰야 합니다.


## 출력 형식

- 사용자의 의도가 MEDICAL인 경우
```json
{
  "question" : "...",
  "intent" : ["..."],
  "execution_plan" : [
    {"node" : "..."},
    {"node" : "..."}
  ]
}
```

---

### 예시

---
- 질문 : 최근 건강검진 결과 알려줘
- 대답 :
```json
{
  "question" : "최근 건강검진 결과 알려줘",
  "intent" : ["MEDICAL"],
  "execution_plan" : [
    {"node" : "total_explain_node"}
  ]
}
```

---

- 질문 : 공복 혈당 수치 어때?
- 대답 :
```json
{
  "question" : "공복 혈당 수치 어때?",
  "intent" : ["MEDICAL"],
  "execution_plan" : [
    {"node" : "mapping_node"},
    {"node" : "is_normal_node"}
  ]
}
```

---
- 질문 : 집가고싶다
- 대답 :
```json
{
  "question" : "집가고싶다",
  "intent" : ["CHAT"],
  "execution_plan" : [
    {"node" : "chat_node"}
  ]
}
```
